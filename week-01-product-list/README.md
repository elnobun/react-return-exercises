# Week 1: Product list

A searchable, filterable list of products built with React and TypeScript. Part of my 16-week return to frontend development; see the [exercise index](../README.md).

## Run it

```bash
npm install
npm run dev
```

Other scripts: `npm run build`, `npm run lint`.

## Stack

React 19 · TypeScript · Vite 8 · ESLint

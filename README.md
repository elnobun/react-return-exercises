# React Return Exercises

Weekly React and TypeScript exercises from my 16-week return to frontend development (November 2026 – March 2027). Each exercise is built without a tutorial. The larger portfolio projects live in their own repositories.

## Exercises

| Week | Exercise | What it practises | Status |
| --- | --- | --- | --- |
| 1 | [Product list](./week-01-product-list) | Components, props, state, filtering and searching a list | Done |

Status values: In progress · Done · Needs rework

## Running an exercise

Each folder is a separate Vite + React + TypeScript app.

```bash
cd week-01-product-list
npm install
npm run dev
```

## How I work in this repository

- One folder per exercise, named `week-NN-short-name`.
- One branch per exercise, merged into `main` through a pull request.
- `main` always runs.
- AI tools are used for review and explanation only; the code is written by me first.

## Stack

React · TypeScript · Vite · Vitest · React Testing Library
